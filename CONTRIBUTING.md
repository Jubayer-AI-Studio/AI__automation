# Contributing to AI__automation

Thank you for your interest in contributing to **AI__automation** — 24/7 Autonomous AI Social Media & Video Automator.

We follow strict **Google Developer Standards**, clean code principles, and conventional commits to maintain enterprise stability.

---

## 🛠️ Development Setup & Workflow

1. **Fork & Clone:**
   ```bash
   git clone https://github.com/Jubayer-AI-Studio/AI__automation.git
   cd AI__automation
   ```

2. **Initialize Environment:**
   ```bash
   pip install -r requirements.txt && python bot.py
   ```

3. **Branching Convention:**
   Create a dedicated branch for your contribution:
   ```bash
   git checkout -b feat/your-feature-name
   # or
   git checkout -b fix/your-bugfix-name
   ```

---

## 📝 Conventional Commits Standard

All commit messages must follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:
* `feat:` A new feature or capability
* `fix:` A bug fix
* `docs:` Documentation improvements
* `perf:` Performance optimizations
* `refactor:` Code restructuring without logic change
* `ci:` CI/CD pipeline or workflow changes

Example:
```bash
git commit -m "feat(ui): add responsive dark mode toggle with local storage persistence"
```

---

## 📬 Submitting a Pull Request (PR)

1. Ensure zero syntax errors, linting warnings, or broken tests.
2. Push your branch to GitHub:
   ```bash
   git push origin feat/your-feature-name
   ```
3. Open a Pull Request against the `main` branch.
4. Fill out the PR template thoroughly. Maintainers will review within 24-48 hours.
