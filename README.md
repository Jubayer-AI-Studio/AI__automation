# ⚡ Unified AI Social Media & Content Automator
> **24/7 Autonomous AI Assistant, Smart Reels Commenter & Automated Content Production Pipeline**

A modular automation engine combining large language model intelligence (Google Gemini) with browser automation and mobile bot workers to streamline social media workflows and video production.

---

## 🌟 Core Modules

### 1. 🤖 24/7 Telegram Personal AI Worker (`telegram_assistant_worker.py`)
* Background daemon acting as your continuous cloud & desktop dispatcher.
* Receives voice notes and instructions via Telegram, executes local tasks, and replies in real time.

### 2. 💬 Smart Reels & Video AI Commenter (`comment_bot/`)
* Automatically parses viral posts and reels, understanding the context using LLMs.
* Generates natural human-like comments with randomized jitter delays to prevent platform bot detection.
* Instant Telegram alerts on every action taken.

### 3. 📬 Messenger AI Assistant (`messenger_bot/`)
* Handles direct inbound inquiries with automated, intelligent responses.

### 4. 🎬 Short-Form Video & Content Engine (`video_production/`)
* Automates video clipping, subtitle styling, voiceover synchronization, and batch rendering via FFmpeg and MoviePy.

```bash
# 1. Clone repository
git clone https://github.com/monisharani333022-eng/AI__automation.git
cd AI__automation

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure credentials
cp .env.example .env

# 4. Launch All-In-One Automator
Run_All_In_One_Desktop_AI.bat
```
